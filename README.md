# Character Visual QA

檢查靜態平面設計（海報、紅包、春聯、賀卡、包裝、社群素材）中的角色，是否與參考圖一致。不處理動畫、3D 或影片。

> 規則是維護者整理的非官方筆記，不代表任何權利人、品牌方或機關的設定或驗收標準。只有維護者修改規則。

## 使用方式

1. 準備設計稿，說明畫的是哪個角色、用在哪裡。
2. 把設計稿、[checklist.md](checklist.md) 與參考圖一起交給 Agent。
3. Agent 依 `checklist.md` 的報告格式回報。對規則的疑問寫在報告的「待維護者確認」，不要改 `checklist.md`。

可直接交給 Agent：

> 請依 `checklist.md` 檢查我提供的設計稿，比對我提供的參考圖中對應角色的圖片。逐項回報結果、位置、參考圖、是否影響辨識與最小修正建議。看得到但無法依檢核表判斷時用 REVIEW，看不到時用 NOT OBSERVABLE。不要重新設計角色，也不要只因畫風不同就判定失真。

只放入已取得使用權的素材。Agent 結果僅供輔助，不等於正式驗收。
